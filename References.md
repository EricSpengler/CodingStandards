# References

This document draws on established, external references rather than inventing conventions from scratch. Individual rules above don't cite a specific source — this list is where to look further if you want the fuller context behind a given rule.

- C++ Core Guidelines — https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines

- Google C++ Style Guide — https://google.github.io/styleguide/cppguide.html

- LLVM Coding Standards — https://llvm.org/docs/CodingStandards.html

- SEI CERT C++ Coding Standard — https://wiki.sei.cmu.edu/confluence/display/cplusplus

- Doxygen Manual — https://www.doxygen.nl/manual/index.html

- Conventional Commits — https://www.conventionalcommits.org/en/v1.0.0/

- Semantic Versioning 2.0.0 — https://semver.org/spec/v2.0.0.html

- GitHub Flow — https://docs.github.com/en/get-started/quickstart/github-flow

- Gitflow (Vincent Driessen's original branching model) — https://nvie.com/posts/a-successful-git-branching-model/
